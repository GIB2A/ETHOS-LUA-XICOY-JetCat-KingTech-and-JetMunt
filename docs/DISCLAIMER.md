# Disclaimer

GIB2A is telemetry-only informational software supplied “AS IS”, without warranty.
Telemetry can be missing, delayed or wrong. The widget does not control the
turbine, ECU, pump, receiver, servos or aircraft. Restart is an ECU-status alarm;
it does not trigger a restart.

GIB2A is an independent project and is not affiliated with any ECU, turbine or
radio manufacturer. No manufacturer has certified GIB2A unless explicit evidence
says otherwise.
Follow manufacturer procedures, field rules and applicable regulations. Validate
all sources, thresholds and alarms on the ground. The pilot remains responsible
for safe operation, and alarms never replace pilot monitoring.
