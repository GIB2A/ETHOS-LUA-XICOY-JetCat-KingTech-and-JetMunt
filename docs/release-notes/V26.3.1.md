# GIB2A V26.3.1

## English

V26.3.1 is a maintenance release for ETHOS system-source compatibility.

- corrected ETHOS system-source handling for receiver voltage
- corrected RSSI 2.4 GHz source handling
- corrected RSSI 900 MHz source handling
- RSSI values now display an explicit `%` unit
- no change to turbine telemetry AppID mappings
- no change to Xicoy or EnJet auto-bind logic

## Français

V26.3.1 est une version de maintenance consacrée à la compatibilité des
sources système ETHOS.

- correction de la lecture de la tension récepteur comme source système ETHOS
- correction de la source RSSI 2,4 GHz
- correction de la source RSSI 900 MHz
- affichage explicite de l’unité `%` pour les valeurs RSSI
- aucune modification des AppID de télémétrie turbine
- aucune modification de l’auto-bind Xicoy ou EnJet
