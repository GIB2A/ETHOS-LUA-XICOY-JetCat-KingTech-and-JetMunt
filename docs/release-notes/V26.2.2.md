# GIB2A V26.2.2

## English

### Summary
V26.2.2 expands ECU telemetry while preserving the pilot-readable ETHOS
dashboard and telemetry-only safety model.

### Highlights and compatibility
- Xicoy Basic, Extended and Maximum with AppID auto-bind
- Enjet DTA auto-bind
- Manual assignment and ECU status support for Linton, KingTech, Swiwin, JetCat
- Radio THR, ECU THR, Heli/TP RPM and Xicoy Fuel Level After Restart
- Fixed 50%/25% fuel callouts; configurable 35%/15% defaults
- FlameOut and Restart transition alarms

Install the SD archive at `SCRIPTS/GIB2A/main.lua`. When upgrading from V1.1,
back up settings, replace the widget, rediscover telemetry and verify all sources.
Install `GIB2A-Xicoy-ProHub-Widget-V26.2.2-ETHOS-Suite.zip` through
`Lua Library` -> `Install from local .zip`. It uses the manifest schema, stable
key and `GIB2A` folder validated in the official V1.1 Suite package. Restart
detects ECU status and never restarts the engine.

## Français

### Résumé
V26.2.2 étend la télémétrie ECU tout en conservant le tableau de bord ETHOS
lisible en vol et un fonctionnement strictement limité à la télémétrie.

### Nouveautés et compatibilité
- Xicoy Basic, Extended et Maximum avec auto-bind AppID
- auto-bind Enjet DTA
- affectation manuelle et statuts ECU Linton, KingTech, Swiwin, JetCat
- radio THR, ECU THR, Heli/TP RPM et Fuel Level After Restart Xicoy
- callouts carburant fixes 50 %/25 % ; seuils par défaut 35 %/15 %
- alarmes de transition FlameOut et Restart

Installer le ZIP SD dans `SCRIPTS/GIB2A/main.lua`. Depuis V1.1, sauvegarder les
réglages, remplacer le widget, redécouvrir la télémétrie et vérifier les sources.
Le paquet ETHOS Suite utilise le schéma de manifeste validé dans le paquet Suite
officiel V1.1. Restart détecte un statut ECU et ne redémarre jamais la turbine.
