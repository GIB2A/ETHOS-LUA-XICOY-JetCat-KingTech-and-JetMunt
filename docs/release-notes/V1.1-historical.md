# GIBA — Xicoy ProHub Turbine Telemetry Widget (ETHOS) — V1.1

## Release content
- ETHOS Lua widget for Xicoy ProHub turbine telemetry
- Pilot-focused dashboard with RPM, EGT, Pump and Fuel
- ECU status decoding
- Basic / Expert setup mode
- Optional Extended / Maximum telemetry support
- Fuel alarms with optional audio files and haptic alert
- Theme selection

## Installation
1. Download the ZIP file attached to this release.
2. Extract the archive.
3. Copy the folder so the SD card path is exactly:
   `SCRIPTS/GIB2A/main.lua`
4. Reboot the radio.
5. Discover sensors in ETHOS and assign them in widget settings.

## Important
- Do not create an extra nested folder.
- ProHub must be configured in FrSky mode.
- Some sensors may require DIY Auto Detect in ETHOS.
