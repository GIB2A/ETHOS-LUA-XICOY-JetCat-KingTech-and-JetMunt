# GIB2A V26.3.0

## English

### Summary

V26.3.0 redesigns the pilot-facing dashboard while preserving the validated
telemetry-only behavior and the telemetry capabilities already available in
V26.2.2.

### Changes since V26.2.2

- new main dashboard
- centralized ECU status and flight timer
- external GIB2A PNG logo
- left and right telemetry-information panels
- typography adapted to the number of visible sensors
- new RPM rendering
- new EGT rendering
- new pump rendering
- new fuel rendering

Install the SD archive at `SCRIPTS/GIB2A/`. Both `main.lua` and
`gib2a_logo_ethos_180.png` are required. For ETHOS Suite, uninstall the previous
GIB2A package before installing V26.3.0.

## Français

### Résumé

V26.3.0 renouvelle le tableau de bord destiné au pilote tout en conservant le
fonctionnement validé strictement limité à la télémétrie et les capacités déjà
présentes en V26.2.2.

### Changements depuis V26.2.2

- nouveau tableau de bord principal
- statut ECU et chrono centralisés
- logo GIB2A PNG externe
- panneaux d’informations télémétriques gauche et droit
- police adaptée au nombre de capteurs visibles
- nouveau rendu RPM
- nouveau rendu EGT
- nouveau rendu pompe
- nouveau rendu carburant

Installer le ZIP SD dans `SCRIPTS/GIB2A/`. Les fichiers `main.lua` et
`gib2a_logo_ethos_180.png` sont tous deux obligatoires. Pour ETHOS Suite,
désinstaller l’ancien paquet GIB2A avant d’installer V26.3.0.
