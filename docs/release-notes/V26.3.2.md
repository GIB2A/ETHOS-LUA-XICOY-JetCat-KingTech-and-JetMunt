# GIB2A V26.3.2

GIB2A V26.3.2 is a major telemetry and robustness update for FrSky ETHOS
turbine users.

## Highlights

- New dashboard interface
- Improved gauge and sensor-information readability
- JetCat Engine 1 auto-binding
- 11 JetCat Engine 1 telemetry sensors supported by auto-bind
- Official JetCat EngState decoding aligned with JetCat ETHOS v0.9.24
- JetCat shutdown-condition support, including legacy formats such as `-102`
- JetCat FlameOut and Auto-Restart alerts
- Xicoy ProHub Basic, Extended and Maximum auto-binding
- EnJet DTA auto-binding
- Improved ECU source isolation when changing turbine manufacturer
- General RxBatt, RSSI, DIY, timer and throttle sources retained across ECU changes
- Internal persistence and `wakeup()` refactoring with static tables
- Reduced repetitive Lua code
- Telemetry reads remain outside `paint()`
- Manual telemetry assignment retained for Linton/KAVAN, KingTech and Swiwin
- Xicoy FlameOut and Restart alerts retained

JetCat Engine 1 auto-binding supports:

- EngRpm1
- EngEgt1
- EngPumpV1
- EngEcuV1
- EngCurrent1
- EngFuel1
- EngFuelFlow1
- EngAlt1
- EngBattCap1
- EngShaftRpm1
- EngState1

Engine 2, 3 and 4 are not automatically bound in this release.

Tested and validated on FrSky ETHOS radio hardware.

## IMPORTANT

Existing users should follow the documented update procedure before installing
V26.3.2. Uninstall or remove the previous widget version before installing this
release.
