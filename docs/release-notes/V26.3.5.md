# GIB2A V26.3.5

## Compatibility

- Telemetry-only widget for FrSky ETHOS.
- Responsive dashboard profiles cover FULL, MEDIUM, MEDIUM-large and smaller widget windows without radio-model detection.
- Existing FULL 800x480 geometry is preserved.

## Telemetry and Auto Bind

- Enjet V1.53 mono-turbine Auto Bind keeps confirmed AppIDs authoritative, then resolves remaining sensors by exact and unique ETHOS names.
- Duplicate Enjet source assignment is prevented across both binding passes.
- Enjet status codes 3, 4 and 9 are aligned with the observed V1.53 states.
- Existing Xicoy and JetCat mappings remain available.

## Display

- The MEDIUM layout adapts to the usable ETHOS widget height on X14/X14RS and X18/X18S-class screens.
- Wide MEDIUM layouts use enlarged RPM, EGT and PUMP gauges.
- Telemetry side panels are enabled on wide windows from 320 pixels of usable height.
- RPM, EGT and PUMP values automatically select the largest font that fits inside the gauge without overlapping its label.

## Documentation

- Added a standalone JetCat FrSky Sensor ID reference sheet.
- Added a standalone Xicoy ProHub FrSky Sensor ID reference sheet.
- Corrected Xicoy Pump RPM Extended from `0x4403` to `0x4404`; Battery Voltage Extended remains `0x4403`.

## Installation

- Remove any previous GIB2A installation before installing V26.3.5.
- Use the dedicated ETHOS Suite ZIP for local installation through ETHOS Suite.
- The SD ZIP retains the validated `SCRIPTS/GIB2A` structure for manual installation.
